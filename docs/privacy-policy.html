Kebijakan Privasi

Muslim Hub
Berlaku efektif: 22 Agustus 2026 · v1.0

1. Pendahuluan

Muslim Hub ("Aplikasi") adalah aplikasi islami yang menyediakan Al Qur'an, jadwal shalat, dzikir, doa, hadits, dan konten islami lainnya. Kebijakan Privasi ini menjelaskan bagaimana Aplikasi menangani data saat Anda menggunakannya.

Pengembang: Rifqi Dias · Email: rifqidias6@gmail.com

2. Prinsip Utama

Tanpa akunTanpa iklanTanpa pelacakTanpa profil pengguna

Aplikasi tidak meminta pendaftaran akun, tidak menampilkan iklan, tidak menggunakan SDK analitik atau pelacakan pihak ketiga, dan tidak menjual atau membagikan data Anda kepada siapa pun untuk tujuan pemasaran.

3. Izin & Data yang Digunakan

  • Lokasi (perkiraan) — digunakan hanya untuk menampilkan jadwal shalat sesuai wilayah Anda. Deteksi dilakukan berbasis alamat IP melalui layanan pihak ketiga dan bersifat sementara (ephemeral): tidak disimpan di perangkat dan tidak dikirim ke server kami.
  • Foto / Media (opsional) — hanya digunakan bila Anda menyimpan wallpaper islami ke galeri. Aplikasi tidak membaca atau mengunggah foto Anda.
  • Internet — untuk mengambil konten (Al Qur'an, jadwal shalat, hadits, doa) dari API publik.

4. Data yang Disimpan di Perangkat Anda

Preferensi berikut disimpan hanya di perangkat Anda (penyimpanan lokal aplikasi) dan tidak pernah dikirim ke server mana pun:

  • Penanda bacaan terakhir (surah / halaman mushaf)
  • Favorit Asmaul Husna
  • Pilihan kota, tema terang/gelap, dan bahasa
  • Riwayat percakapan fitur Tanya AI (tersimpan lokal, dapat dihapus kapan saja)

Menghapus data aplikasi atau mencopot pemasangan Aplikasi akan menghapus seluruh data tersebut secara permanen.

5. Layanan Pihak Ketiga

Aplikasi mengambil konten dari API publik berikut. Permintaan ke layanan ini membawa alamat IP Anda sebagaimana lazimnya komunikasi internet, namun Aplikasi tidak mengirimkan identitas, nama, atau data pribadi lainnya:

  • api.myquran.com — jadwal shalat & daftar kota (Indonesia)
  • api.qalbun.my.id — konten islami (hadits, doa, dzikir) dan fitur Tanya AI. Pertanyaan yang Anda kirim melalui fitur Tanya AI diproses oleh layanan ini dan jangan menyertakan informasi pribadi dalam pertanyaan Anda.
  • raw.githubusercontent.com (QuranJSON) & api.alquran.cloud — teks Al Qur'an, terjemahan, transliterasi, dan tafsir

6. Keamanan & Retensi

Aplikasi tidak menyimpan data pribadi di server milik pengembang, sehingga tidak ada retensi data di sisi kami. Data preferensi lokal tersedia hanya selama Aplikasi terpasang di perangkat Anda.

7. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 13 tahun dan tidak sengaja mengumpulkan data dari anak-anak. Konten Aplikasi aman digunakan seluruh keluarga.

8. Perubahan Kebijakan

Bila Kebijakan Privasi ini diperbarui, versi terbaru akan dipublikasikan di halaman ini beserta tanggal pembaruan.
